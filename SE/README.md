# Chatinbox Scenarios App

Bu uygulama Chatinbox'un roadmap senaryolarını görselleştirmek ve detaylandırmak için oluşturulmuştur.

## Nasıl Çalıştırılır

1. Terminali açın: `cd scenarios`
2. Bağımlılıkları yükleyin: `npm install`
3. Uygulamayı başlatın: `npm run dev`
4. Tarayıcıda açın: `http://localhost:5173`

## İçerik

- **S1: Negatif Yorum Kurtarma**: İlk senaryo detaylandırıldı. 
- 5 farklı akış örneği eklendi (Kargo hasarı, Yanlış beden, Sahte ürün iddiası vb.)
- Teknik gereksinimler listelendi.
- Premium tasarım uygulandı.

## Teknolojiler

- Vite + React
- Vanilla CSS (Premium Dark Theme)
- Lucide React Icons
